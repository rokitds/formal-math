## The one idea for this week

A Lean proof is a conversation. You type a step (a *tactic*), and Lean answers with what is
left to prove: the *goal state*. Everything above the `⊢` is what you know; the line after it is
what you must show. A proof is finished when Lean says **No goals**.

Paper proofs hide the goal state in the author's head. Lean shows it after every step, which is
why reading the goal state is the most important skill in this course.

## Get set up

Follow [SETUP.md](https://github.com/rokitds/formal-math/blob/main/learning/SETUP.md) to install
Lean and the VS Code extension. If you want to start before installing anything, every sheet below
has an **Open in browser** button that loads it into the official online editor.

## Reading

Work through these chapters of [*Mathematics in Lean*](https://leanprover-community.github.io/mathematics_in_lean/)
alongside the sheets:

- Chapter 2.1 and 2.2, *Calculating* and *Proving identities*, for sheet 1.
- Chapter 3.1 to 3.5, *Logic*, for sheet 2.
- Chapter 4.1, *Sets*, for sheet 3.

## Sheet 3: sets

<LeanSheet file="Week01/E03_Sets.lean" />

In Mathlib a set is a predicate, so set proofs are logic proofs in disguise. The headline claim
of the VP ≠ VNP project is a set statement, `VP F ⊂ VNP F`, and the last exercise is a toy
version of its shape.
